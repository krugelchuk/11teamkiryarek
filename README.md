# Qadam11 — Digital HR для Jana Post

Команда №11: Кирилл, Абзал, Нурс. Кейс №2.

## Запуск готовой версии

Нужен Python 3.10 или новее. Полностью распакуйте архив, откройте папку Qadam11 и запустите start-demo.bat. Затем откройте http://localhost:8000.
Для Linux/macOS: sh start-demo.sh.

Node.js для запуска готового приложения не требуется: сборка frontend уже включена.
Если порт 8000 занят, остановите прежний сервер либо выполните:
python scripts/prepare_demo.py
python server.py --db data/demo.db --port 8001

## Демонстрационные аккаунты

Пароль всех стандартных демо-аккаунтов: Demo2026!
- Сотрудник: employee@demo.local
- Руководитель: manager@demo.local
- HR: hr@demo.local
- Другая команда: other@demo.local и other-manager@demo.local

Все пользователи и учебные кадровые данные вымышлены. Демо-база создаётся при первом запуске; повторный запуск сохраняет прогресс.
Для своей организации без заготовленных людей запустите start.bat и создайте первого HR через форму.

## Что показать

1. Сотрудник создаёт заявку на отпуск; руководитель принимает решение; сотрудник получает уведомление, историю и обновлённый остаток.
2. Jana Academy: назначение курса через HR → «Уведомления», уроки, итоговый тест, сохранение прогресса.
3. AI Jana: вопрос «Как подать заявку на отпуск?» и открываемый источник.
4. «Команда на карте»: 13 настоящих точек Jana Post в Астане, доступные роли сотрудники, календарь отпусков и минимум персонала, который задаёт HR.
5. HR → «Корпоративные системы»: примеры будущего обмена с 1С:ЗУП и Documentolog. Это локальные заглушки, реальные системы не подключены.

## Gemini

Для внешней модели остановите прежний сервер и запустите start-gemini.bat. Введите собственный ключ в скрытый ввод консоли. Доступная стабильная текстовая Flash-модель выбирается автоматически. Ключ сохраняется только локально в data/gemini.json. Проверка: check-gemini.bat.

Ключ автора в архив не включён. Без ключа работает локальный поиск по базе знаний. Внешняя модель получает вопрос и разрешённые роли документы; ответ проверяется по источникам. При ошибке API приложение явно сообщает о локальном поиске. Наличие квоты зависит от аккаунта провайдера.

## Стек и сборка

React, TypeScript, Vite; Python 3 со стандартной библиотекой, REST API; SQLite; Gemini API; Leaflet и OpenStreetMap. Адреса и координаты точек — из публичных карточек 2ГИС, ссылки сохранены в fixtures/astana_branches.json. Для подложки карты нужен интернет. Это выборка точек сети, реальные сотрудники компании не импортировались.

Изменить frontend: cd frontend, затем npm ci и npm run build.
Проверить backend: python -m unittest discover -s tests -v.
Дополнительный тест TypeScript API-клиента требует установленного Node.js и frontend/node_modules после npm ci.
Проверка сохранения данных между процессами: python scripts/verify_release.py.

На проверенной версии прошли 68 автоматических тестов. Полный визуальный проход всех экранов браузерным инструментом и запуск Docker в среде разработки не подтверждены.

## Документация

- ARCHITECTURE.md — схема архитектуры и проверки доступа.
- API_REFERENCE.md и API_CONTRACT.md — HTTP API.
- GEMINI_QUICKSTART.md — подключение модели.
- MAP_AND_CALENDAR.md — карта, роли и расчёт отпусков.
- ENTERPRISE_INTEGRATIONS.md — место будущих корпоративных интеграций.
