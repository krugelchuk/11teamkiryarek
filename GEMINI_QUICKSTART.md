# Gemini: осталось вставить ключ

1. Получите ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Остановите прежний сервер на порту 8000. Откройте **start-gemini.bat**.
3. Вставьте ключ в консоли и нажмите Enter. Ввод скрыт: символы не отображаются. Ключ не нужно вставлять в код, браузер или переписку.
4. Откройте http://localhost:8000/assistant и задайте «Как подать заявку на отпуск?». У подтверждённого ответа модели появится «Модель · проверенные цитаты». При отказе API помощник явно покажет локальный режим.

Модель выбирается через официальный models.list из доступных стабильных текстовых Flash-моделей с generateContent. Предпочтение более новой версии и обычному Flash перед Flash Lite той же версии. Preview, экспериментальные и мультимодальные специализированные модели не выбираются. Если подходящей модели нет, задайте доступную вашему аккаунту модель в GEMINI_MODEL. Список кешируется на 5 минут, ошибки — на 30 секунд. Без доступного API остаётся локальный поиск.

Повторный запуск использует сохранённый ключ. Локальные настройки — `data/gemini.json`: это обычный файл с секретом, его нельзя отправлять другим людям. Он исключён из Git, архивов и HTTP-раздачи. Чтобы заменить ключ: `python -X utf8 scripts/start_gemini.py --demo --new-key` (уберите GEMINI_API_KEY из окружения, если он задан). Удаление этого файла отключает сохранённый ключ.

Проверка: **check-gemini.bat**. Код 0 — подтверждённый живой ответ с источником и корректные отказы, 1 — ошибка или откат вместо положительного ответа модели. На локальном ключе пользователя живой Gemini проверен; в архив ключ не включён. Наличие настроенного ключа в статусе ещё не подтверждает доступность или квоту.

Для своей организации: `python -X utf8 scripts/start_gemini.py` без --demo. Для Linux/macOS: `python3 scripts/start_gemini.py --demo`. Для другого порта задайте переменную PORT перед запуском.

Внешнему API отправляются вопрос и до четырёх опубликованных документов, разрешённых роли. Личные профили, остатки отпусков и сотрудники карты не отправляются. Ответ модели принимается только с существующим id источника и дословной цитатой. Карта работает независимо от Gemini и не требует ключа 2ГИС.

Официальная документация: [ключи](https://ai.google.dev/gemini-api/docs/api-key), [список моделей](https://ai.google.dev/api/models).

«Привет» и «Что ты умеешь?» дают подсказку о возможностях. Это локальный диалог, а не тест подключения модели. Для проверки модели задайте «Как подать заявку на отпуск?» и проверьте подпись «Модель · проверенные цитаты».
